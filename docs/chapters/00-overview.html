概要 — スマホからClaude Codeを操作する

AndroidスマホからPC（WSL2）上のClaude Code CLIを操作する方法を解説するガイド。 Tailscale VPN + Termux + SSH + tmux の組み合わせで、外出先からもPCの開発環境を操作できる。

前提条件

条件 詳細
PC側 Windows + WSL2 Ubuntu、Claude Code CLI導入済み
蓋閉じ設定 「カバーを閉じても何もしない」に変更済み（スリープ防止）
Tailscale PC・スマホ両方にインストール＆ログイン済み
ネットワーク 両デバイスがTailscale上でオンライン

デバイス一覧

デバイス Tailscale IP 状態
PC（WIN-E2IAVN1ESMH） 100.115.156.98 オンライン（常時必要）
razr-50s 100.80.187.46 接続済み
galaxy-z-flip7 100.106.53.69 設定済み

⚠️ Tailscale IP は環境により変動する場合がある。実際の値は各デバイスのTailscaleアプリで確認すること。
