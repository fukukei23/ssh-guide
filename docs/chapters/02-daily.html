毎回の手順（クイックリファレンス）

3行で分かる

  1. Tailscale IPを確認 → ssh yn4416@<IP> でPCに接続
  2. tmux attach -t claude で前回のセッションを再開
  3. 終了時は detach（Ctrl+b d）で切らずに保存・離脱

接続（3行）

ssh yn4416@100.115.156.98
tmux attach -t claude

新規セッション

ssh yn4416@100.115.156.98
tmux new -s claude
claude

tmux操作

操作 方法
抜ける（セッション維持） Ctrl+B → D
戻る tmux attach -t claude
一覧 tmux ls
終了 tmux kill-session -t claude

切断

  1. Ctrl+B → D（tmuxデタッチ）
  2. exit（SSH切断）

Claude Codeはtmux内で動き続けます。接続を切ってもセッションは維持されます。

スマホ → PC への引き継ぎ

スマホの作業をPCに引き継ぐときも、PC側で同じセッションにアタッチするだけです。

# PCのWSLターミナルで
tmux attach -t claude

💡 詳細手順（同時ミラーリング・逆方向・トラブル時）は 05 スマホからPCへの引き継ぎ を参照。
