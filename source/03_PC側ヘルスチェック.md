# PC側ヘルスチェック — つながらない時に診断

> **3行で分かる**
> 1. つながらない時はPC側で「Tailscale状態 → WSL起動 → sshd」の3点を順に確認
> 2. `tailscale status` / WSL起動確認 / `sudo service ssh status` を叩く
> 3. だいたいWSL未起動かTailscale未接続が原因

スマホからSSH接続できない時、PC側（WSL2）で以下3点を順に確認する。

## 1. Tailscale 状態確認（PC側）

WSLターミナルでWindows側のTailscaleを叩く:

```bash
"/mnt/c/Program Files/Tailscale/tailscale.exe" status
```

**判定基準**: 出力に自PC（`100.115.156.98`）が `active` / `online` で表示されること。
- 表示されない → Tailscaleが起動していない。Windows側でTailscaleアプリを起動。

## 2. sshd LISTEN確認（WSL側・ポート22）

```bash
ss -tlnp | grep :22
```

**判定基準**: `0.0.0.0:22` または `*:22` が `LISTEN` として表示されること。
- 表示されない → WSL内のSSHサーバー（sshd）が起動していない。`sudo service ssh start` で起動（※要ユーザー確認・sudo実行前）。

## 3. 無操作スリープ設定確認（Windows）

```bash
powershell.exe -NoProfile -Command "[Console]::OutputEncoding=[System.Text.Encoding]::UTF8; powercfg /query SCHEME_CURRENT SUB_SLEEP 29f6c1db-86da-48c5-9fdb-f2b67b1f44da"
```

**判定基準**: `STANDBYIDLE` の AC電源設定（`Current AC Power Setting Index`）が `0x00000000`（=スリープしない）であること。
- `0x00000000` 以外 → スリープに入るとSSH接続が切れる。「カバーを閉じても何もしない」設定を見直す（01章 Step 1）。

## 診断フロー

```
つながらない
  ↓
1. Tailscale status → online?
  ├─ No → Tailscale起動
  └─ Yes ↓
2. ss -tlnp → :22 LISTEN?
  ├─ No → sshd 起動
  └─ Yes ↓
3. powercfg → STANDBYIDLE = 0?
  ├─ No → スリープ設定変更
  └─ Yes → 別原因（04章 トラブル対応へ）
```
