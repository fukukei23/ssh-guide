# 初回セットアップ（約15分）

> **3行で分かる**
> 1. Windows側で「蓋閉じスリープ防止」を設定し、WSL2/Ubuntu環境を整える
> 2. PCとスマホ両方にTailscaleを入れ、VPNで繋がるようにする
> 3. TermuxにSSH鍵を登録し、tmuxでセッションが切れないようにする

## Step 1: Windows設定（PC側）

1. **蓋閉じスリープ防止**
   - 設定 → システム → 電源 → 画面とスリープ → 「カバーを閉じたとき」→「何もしない」
   - または管理者PowerShell: `powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0 && powercfg /setactive SCHEME_CURRENT`

2. **Tailscaleインストール**（未導入の場合）
   - `winget install Tailscale.Tailscale`
   - 起動してログイン

## Step 2: Tailscale設定（スマホ側）

1. **Play Store で Tailscale インストール**
2. ログイン（PCと同じアカウント）
3. 接続確認: PCのIP（100.115.156.98）が見えるか

## Step 3: Termux設定（スマホ側）

1. **F-Droid から Termux インストール**（Play Store版は古いのでNG）
   - https://f-droid.org/packages/com.termux/
2. Termux起動
3. パッケージ更新: `pkg update && pkg upgrade -y`
4. OpenSSH インストール: `pkg install openssh -y`

## Step 4: SSH鍵作成（スマホ側）

```bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
```

既に鍵がある場合は上書き不要（`n` でスキップ）。

## Step 5: 公開鍵をPCに登録（スマホ側）

```bash
ssh-copy-id yn4416@100.115.156.98
```

PCのパスワードを入力。成功すると `Number of key(s) added: 1` と表示。

> ⚠️ **注意**: ユーザー名を省略しないこと。`ssh 100.115.156.98` だけだとTermuxのユーザー名（`u0_aXX`）になりパスワードを聞かれる。必ず `yn4416@` を付ける。

## Step 6: パスワードなしログイン確認（スマホ側）

```bash
ssh yn4416@100.115.156.98
```

パスワードなしでPCプロンプト（`yn4416@WIN-E2IAVN1ESMH:~$`）が出れば成功。

## Step 7: tmux + Claude Code起動

```bash
tmux new -s claude
claude
```

## 既存設定ありの場合（約3分）

以前セットアップ済みで鍵・Tailscaleが残っている場合:

1. Termux起動
2. `ssh yn4416@100.115.156.98` — パスワードなしで即接続
3. `tmux attach -t claude` — 既存セッションに復帰
4. （セッションがない場合）`tmux new -s claude` → `claude`
