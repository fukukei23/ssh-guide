# 概要 — スマホからClaude Codeを操作する

> **3行で分かる**
> 1. Tailscale VPN + Termux + SSH + tmux の4つ組みで、スマホからPC（WSL2）のClaude Codeを操作
> 2. 外出先でも開発環境を止めずに続きから再開できる（tmuxがセッションを保持）
> 3. 最初は「初回セットアップ(約15分)」、以降は「毎回の手順(3行）」だけで運用

AndroidスマホからPC（WSL2）上のClaude Code CLIを操作する方法を解説するガイド。
Tailscale VPN + Termux + SSH + tmux の組み合わせで、外出先からもPCの開発環境を操作できる。

## 前提条件

| 条件 | 詳細 |
|---|---|
| PC側 | Windows + WSL2 Ubuntu、Claude Code CLI導入済み |
| 蓋閉じ設定 | 「カバーを閉じても何もしない」に変更済み（スリープ防止） |
| Tailscale | PC・スマホ両方にインストール＆ログイン済み |
| ネットワーク | 両デバイスがTailscale上でオンライン |
